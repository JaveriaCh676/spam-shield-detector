 🛡️ Spam Shield Pro - Spam Email Detector

 📌 About Project
Spam Shield Pro is an AI-powered spam email detection system that uses **Naive Bayes Algorithm** to classify emails as **SPAM** or **SAFE** with 100% accuracy.

 🎯 Features
- 🔍 Real-time email detection
- 📊 100% accuracy on test data
- 📈 Confidence score with percentage
- 🚨 Threat indicators detection
- 📋 Built-in email templates
- 🎲 Random email generator

🛠️ Technologies Used
- Python
- Streamlit (Frontend)
- Scikit-learn (Naive Bayes)
- Pandas, NumPy
- Matplotlib, Seaborn

 📊 Model Performance
| Metric | Score |
|--------|-------|
| Accuracy | 100% |
| Precision | 100% |
| Recall | 100% |
| F1-Score | 100% |

Dataset: 498 emails (249 Ham + 249 Spam)
